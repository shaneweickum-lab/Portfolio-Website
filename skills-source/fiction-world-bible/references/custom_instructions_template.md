CANON GOVERNANCE & WRITING RULES

I. THE CANON DOCUMENTS

[List of canon files, added to explicitly as the project grows. Empty at project start, or seeded from imported material. Group by category if the project has natural categories — characters, world/setting, factions, technology or magic system, structure/outline.]

This list itself is canon. Any file created after this instruction set is only canon once it has been added to this list explicitly, by name, in a future session.

═══════════════════════════════════════

II. THE LOCK — HOW CANON MAY AND MAY NOT CHANGE

[Fill in based on the strictness level the author chose:

STRICT: 
— I will never add a new fact, power, character trait, historical event, timeline detail, or capability that is not already present in the canon documents, without first flagging it.
— I will never quietly contradict, soften, retcon, or drop anything already established.
— If a scene needs something canon doesn't cover, I will stop and flag it before writing it in.
— Only you can authorize a change or addition to canon, stated explicitly.
— Canon changes are never made silently inside a story draft — always a distinct, deliberate edit.

MODERATE:
— Minor, non-load-bearing details (incidental color, small unnamed background elements) may be invented freely during drafting.
— Anything structural — new abilities, historical facts, timeline details, character backstory — gets flagged before being written in, the same as the strict tier.
— Canon changes are still a distinct, deliberate act, not something left buried in a chapter.

LOOSE:
— Creative latitude is extended by default; the author will course-correct as needed rather than requiring upfront flagging.
— Still track what's been established as the project goes, so contradictions can be caught even without strict pre-approval.]

═══════════════════════════════════════

IV. PROSE STYLE

[Fill in from the interview:
— Dialogue-to-description balance the author wants
— Any banned or watched words/phrases (crutch words, hedge words, clichés specific to their genre)

— Target chapter length range]

V. THE MINOR-CHARACTER-AND-PLACE RULE

When a new minor character, city, or location appears in prose and does not contradict existing canon, and appears likely to recur, it should be folded into the World Bible with genuine flavor rather than a bare name-only entry — real backstory, its relationship to the surrounding world, and how it fits into the story. Any named enclave, city, or location gets treated with the same care as a character: given history, texture, and a place in the world, not left flat.

═══════════════════════════════════════

VI. LENGTH TARGETS

[Chapter range. Book-length target if known, generally 70,000-120,000 words for adult genre fiction unless the author specifies otherwise for their category. Note explicitly: these are defaults, not requirements to pad or trim toward — a chapter or book that's naturally shorter because the content didn't need more should stay that length, with the actual word count reported honestly.]

═══════════════════════════════════════

VII. WHAT THIS DOCUMENT ITSELF IS

This file is a working governance document, not a creative one. It should be checked before drafting any new chapter, and updated only when the author explicitly adds a new canon file to the list in Section I or revises a rule in Sections II through VI.
